# Weather App

A weather and news project built with HTML, CSS, and vanilla JavaScript. The app fetches current weather and forecast data for Tooele, Utah, then renders the results into the page.

## Features

- Current weather summary
- Temperature, feels-like temperature, humidity, wind speed, and condition
- Weather icon from OpenWeather
- 5-day forecast cards
- Separate news page
- Responsive card-style layout

## Tech Stack

- HTML
- CSS
- JavaScript
- Fetch API
- OpenWeather API
- News API usage in the news page

## How To Run

Open `index.html` in a browser.

If API content does not load after deployment, check the API provider rules. Some free API tiers only allow browser requests from localhost or require secured/referrer-approved domains.
